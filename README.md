# 记忆演化与三维效果可视化（赛题三 · 加分项 app）

## 启动方式（任选其一，都不需要联网/安装依赖）
- **Windows**：双击 `start.bat`（若 SmartScreen 提示，选「仍要运行」）；也可直接双击 `index.html`。
- **macOS / Linux**：直接双击 `index.html`（或右键用浏览器打开）。`start.bat` 仅 Windows 可用。
- **从压缩包预览**：若在网盘/邮件里直接预览本文件，部分平台会拦截脚本，请先解压整个 ZIP 再打开。
- **在线预览（可选）**：https://chat.fxgqc.top/s3-app-liming/ —— 与包内 `index.html` 同一版本，点开即用。若你的网络访问该域名受限，请直接解压用本地 `index.html`，两者功能完全一致。

纯静态单文件：内联 SVG + 内联数据，**无 CDN、无外部请求、无需联网、无需安装任何依赖**；`index.html` 为唯一入口，双击或浏览器打开即可。

## 页面内容
1. **总览 + KPI 卡**：喂入轮数 / 工具调用 / 记忆条数 / 覆盖对数 / 交付自检（30 秒看懂本页证明什么）
2. **① 记忆演化**：28 轮逐轮条数（总 / USER / MEMORY / daily-log）；随滑块/播放显示**当前轮游标**，已走过区段加粗高亮
3. **② 艾宾浩斯遗忘曲线族**：R = exp(−t/S)，越常被召回越难忘（MemoryBank, arXiv 2305.10250）
4. **③ 现存记忆状态**：45 条 USER 条目，按 有效 / 已被取代 / 已撤回 / 未证实 着色并标版本号；**图随筛选按钮重算**
5. **④ 记忆更新矩阵**：13 行「旧值 → 新值」；**按当前轮自动定位并高亮对应覆盖对**，下拉可逐对查看
6. **⑤ 污染防御 / 角色隔离时间线**：28 轮逐轮记忆动作；**随滑块滚动并高亮当前行**（用户输入中的 PII 已掩码）

## 交互与设计
- 滑块 / 播放 / ←→ 键：逐轮回放；用户原文、动作标签、工具调用、三条累计条实时更新。
- 四处实时联动：① 演化图当前轮游标与已走过区段；⑤ 时间线滚动高亮；③ 状态图随筛选重算；④ 覆盖矩阵按轮次定位并同步对比下拉。
- 顶部提供评审导航（总览 / 交互 / 演化 / 遗忘 / 状态 / 更新 / 时间线）与 24/24 环形自检；交互面板显示当前轮增量。
- 视觉采用内联 CSS/SVG 设计系统（KPI 卡、渐变标题、环形图、面积渐变、卡片阴影、粘性表头、滚动揭示、响应式布局）；不引入 Unity / Blender 等外部运行时，保持单文件离线。
